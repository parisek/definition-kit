# Security policy

## Supported versions

Only the latest release gets security fixes. That is the newest minor release of the newest major version. Older releases get no fixes. To receive a fix, update to the latest release.

## Report a vulnerability

Do not open a public issue.

Use GitHub private vulnerability reporting. Open the
[Security tab](https://github.com/parisek/definition-kit/security) and select
"Report a vulnerability". You can also go to the direct link:
<https://github.com/parisek/definition-kit/security/advisories/new>.

We aim to reply within 7 days.

## What to include

- The affected version.
- The steps to reproduce the problem.
- The impact: what an attacker can do.

## What happens next

We confirm the problem and prepare a fix. The fix ships as a patch release
with a GitHub Security Advisory.
